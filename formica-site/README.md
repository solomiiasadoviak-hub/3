# Formica — сайт с предварительным расчётом стоимости

Сайт для Formica Building Contracting: тёмный стиль варианта «Light», версии на английском и русском, структура по ТЗ. Внутри калькулятор стоимости ремонта, приём заявок, админ-панель и подключение CRM и аналитики.

Сервер на Node.js. Единственная зависимость — `sharp` для сжатия фото, Railway ставит её сам. Запускается на Railway, Render или любом VPS.

## Запуск

```bash
ADMIN_PASSWORD=секрет npm start      # http://localhost:3000
```

| Адрес | Что там |
|---|---|
| `/en`, `/ru` | Главная: Hero, About, Portfolio, Video Journal, How We Work, Estimate/Contact, Footer |
| `/project/<slug>` | Страница проекта: Brief, Scope, Client's Involvement, Before/After, галерея с подписями комнат, видео, кнопка «Discuss a similar project» |
| `/videos` | Полная видеогалерея с фильтром по категориям |
| `/privacy` | Privacy Policy (шаблон, перед публикацией его должен проверить юрист) |
| `/admin` | Админ-панель (логин `admin`, пароль из `ADMIN_PASSWORD`) |

## Деплой на Railway

1. New Project → Deploy from GitHub → этот репозиторий. Railway сам выполнит `npm start`.
2. Добавьте **Volume** и смонтируйте его, например, в `/data`.
3. Переменные окружения:

| Переменная | Зачем |
|---|---|
| `ADMIN_PASSWORD` | пароль для `/admin` (без него админка выключена) |
| `DATA_DIR=/data` | где хранить контент, заявки и загруженные фото и видео. **Без Volume всё это пропадёт при редеплое** |
| `KOMMO_WEBHOOK_URL` | отправка заявок в Kommo (через webhook-интеграцию Kommo или Make/Zapier) |
| `LEAD_WEBHOOK_URL` | любой другой webhook: Make, Zapier, n8n, Google Sheets |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | мгновенное уведомление о новой заявке в Telegram |
| `META_PIXEL_ID`, `META_CAPI_TOKEN` | Meta Conversions API: серверное событие `Lead` |

ID для GTM, GA4 и Meta Pixel вводятся в админке, в разделе **Settings**.

## Калькулятор (Preliminary Estimate)

Мастер из 5 шагов: тип проекта (Full Renovation, Rental-Ready, Commercial Fit-Out) → тип объекта → площадь (м² или sq ft), кухни, санузлы → нужен ли дизайн и уровень отделки (Standard, Premium, Luxury) → доп. опции и сроки старта.

На выходе посетитель видит:
- вилку бюджета в AED;
- цену за м²;
- срок в неделях;
- разбивку по статьям (демонтаж, инженерия, отделка, столярка, кухня, санузлы, дизайн, согласования, мебель и т. д.);
- форму «получить детальное предложение». Заявка сохраняется вместе со всеми параметрами расчёта.

**Все ставки редактируются в админке** (вкладка *Estimator rates*). Цифры в `seed/content.json` ориентировочные, их нужно заменить на реальные ставки Formica.

## Заявки

- Каждая заявка **сначала сохраняется на сервер** (`DATA_DIR/leads.jsonl`), и только потом отправляется в Kommo, Telegram и Meta. Если интеграция упала, заявка не теряется: в админке видно, куда она дошла.
- Некорректный номер телефона не блокирует отправку: заявка сохраняется с пометкой «check number».
- Вместе с заявкой фиксируются UTM-метки, fbclid/gclid, страница, язык и проект, который смотрел клиент.
- Заявки можно смотреть в админке, менять им статус и выгружать в CSV для Excel.

## Админ-панель

- **Projects**: добавление, удаление и порядок проектов; категория (Full, Rental, Commercial) и тип; featured-проекты; тексты на EN и RU; обложка; галерея с подписями комнат; Before/After; загрузка фото.
- **Video Journal**: MP4-загрузка или ссылка на YouTube, Vimeo, Instagram Reel; отдельная обложка; категория; привязка к проекту; вывод на главную.
- **Team**, **Settings** (контакты, видео и фото Hero отдельно для десктопа и телефона, аналитика), **Estimator rates**.

## Реальные проекты с formicadxb.com

В админке во вкладке **Projects** есть две кнопки:
1. **«Загрузить проекты с formicadxb.com»** заменяет демо-проекты на 21 реальный проект: название, район, площадь, вид работ и фото. Потом нажмите **Save changes**.
2. **«Скопировать фото на свой сервер»** скачивает фото со старого сайта на Tilda в `DATA_DIR/uploads` и сжимает их в WebP. Сайт после этого не зависит от Tilda. Нужен подключённый Volume.

Фото, которые вы загружаете через админку, тоже автоматически сжимаются: до 1800 px, WebP. Это делает библиотека `sharp`. Если её нет, фото сохраняются без сжатия.

## Ответы на вопросы из ТЗ

**Instagram Reels → сайт автоматически.** Технически это возможно через Instagram Graph API, но нужен бизнес-аккаунт и токен, который придётся периодически обновлять. Видео при этом отдаются с CDN Instagram по временным ссылкам. Встроенный плеер Instagram тяжёлый и плохо подходит для мобильной скорости. Рекомендация: загружать короткие MP4 (1080p, H.264, 10–60 с) через админку, а ссылку на Reel использовать как запасной вариант (такой формат уже поддерживается).

**AI-калькулятор.** Сейчас расчёт идёт по прозрачной формуле с редактируемыми ставками. Его следующий шаг — подключить LLM, например Claude API. Модель по введённым параметрам и фото объекта писала бы персональный комментарий к смете и уточняющие вопросы. Для этого нужен API-ключ на сервере и отдельный эндпоинт. Вилку цен по-прежнему стоит считать формулой, чтобы цифры оставались под контролем компании.
